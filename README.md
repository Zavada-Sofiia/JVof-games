# JVof games

Платформа для онлайн-ігор з друзями. Перша гра — **Мафія**: друзі додають одне одного за кодом, заходять в одну кімнату, бачать і чують одне одного, а гра сама керує тим, хто в який момент може говорити.

Архітектура — у `architecture_final.pdf` (поза репозиторієм). Коротко:

| Шар | Технологія |
| --- | --- |
| Frontend | React + TypeScript (Vite), Zustand |
| Backend | Node.js + TypeScript (Fastify), Socket.IO |
| Ігровий стан | чистий автомат станів у `packages/game-mafia` (покритий тестами) |
| База | PostgreSQL + Prisma |
| Відео | WebRTC P2P (mesh), сигналізація через Socket.IO |
| Авторизація | email + пароль (argon2id), access-JWT 15 хв + refresh-токен у httpOnly-cookie з ротацією |

## Структура

```
apps/
  web/            React-клієнт: лобі, друзі, кімната, відео, панель гри й адміна
  server/         REST API + ігровий WebSocket + Prisma (схема та міграції в prisma/)
    scripts/bots.ts   боти для тестування без друзів
packages/
  shared/         типи подій, DTO, схеми валідації (zod)
  game-core/      інтерфейси GameEngine/GameModule та спільні блоки: таймери, голосування, черга ходу
  game-mafia/     правила Мафії: ролі, фази, нічні дії, голосування, політика звуку
infra/
  docker-compose.yml   Postgres для локальної розробки
```

## Запуск локально

Потрібні Node.js 22+ і Docker.

```bash
npm install
cp apps/server/.env.example apps/server/.env   # за потреби змініть JWT_SECRET
npm run db:up        # Postgres у Docker (порт 5433)
npm run db:migrate   # створити таблиці
npm run dev          # сервер на :3001 і сайт на http://localhost:5173
```

Листи (підтвердження пошти, відновлення пароля) без `RESEND_API_KEY` не надсилаються, а друкуються в консоль сервера разом із посиланням.

### Тестування без друзів

У кімнату можна запустити ботів, які грають випадково:

```bash
npm run bots -- ABCD 4            # 4 боти в кімнату з кодом ABCD (кімната має бути приватною або публічною)
npm run bots -- ABCD 4 --from=2   # почати з bot2 (якщо ви самі зайшли під bot1)
npm run bots -- ABCD 5 --start    # бот-адмін одразу почне гру
```

Боти реєструються як `bot1@bots.local`, `bot2@bots.local`, … (пароль у `apps/server/scripts/bots.ts`).

Щоб перевірити відео між двома людьми на одному комп'ютері, відкрийте сайт у звичайному вікні та в анонімному (або в іншому браузері) під різними акаунтами.

### Перевірки

```bash
npm test             # тести рушія Мафії (цілі партії без браузера)
npm run typecheck    # перевірка типів усіх пакетів
```

## Як влаштована гра

- **Сервер — єдине джерело правди.** Клієнт надсилає лише наміри («голосую за гравця 4»), сервер перевіряє, чи це дозволено.
- **Ролі не витікають.** Кожен отримує тільки свій `PlayerView`; у спільному стані ролей немає до кінця гри.
- **Політика звуку.** Після кожної зміни фази сервер обчислює, хто кого чує й бачить. Відправник не надсилає трек тим, кому не можна, а отримувач додатково глушить заборонений звук.
- **Мут від адміна** накладається поверх політики гри, гравець сам себе не розмутить.
- **Живий стан** кімнат і партій — у пам'яті сервера. Завершені партії з журналом подій (`game_events`) зберігаються в Postgres: з них будуються історія, статистика й розбір партії.
- **Реконнект.** Якщо гравець випав або відійшов на іншу сторінку, його місце в партії тримається 5 хвилин. Якщо адмін зник на 30 секунд, права переходять іншому. Якщо пішов ведучий-людина, гра переходить на авто-ведучого.

## Нова гра

1. Створити пакет `packages/game-<назва>` з реалізацією `GameEngine` (див. `packages/game-core/src/engine.ts`) і тестами.
2. Описати політику звуку (`getAudioPolicy`) і схему налаштувань (`settingsSchema`).
3. Зареєструвати модуль у `apps/server/src/games/registry.ts` та `apps/web/src/games/registry.ts`, додати клієнтський екран (`ClientGame`).
4. Таблиці кімнат, історії й статистики вже універсальні — нічого міняти не треба.

## Деплой (безкоштовно)

Найпростіше — один сервіс, який віддає і API, і зібраний сайт (`apps/web/dist`), плюс безкоштовна база Neon або Supabase.

У `render.yaml` є шаблон для Render (Blueprint). Потрібно задати змінні:

- `DATABASE_URL` — рядок підключення до Postgres (для Neon — **прямий**, без pooler: так працюють міграції Prisma);
- `WEB_ORIGIN` — лише якщо підключаєте власний домен (інакше сервер бере адресу з `RENDER_EXTERNAL_URL`);
- `JWT_SECRET` — Render згенерує сам;
- за бажанням `RESEND_API_KEY` і `MAIL_FROM` для листів, `TURN_URLS`/`TURN_USERNAME`/`TURN_CREDENTIAL` для складних мереж.

Важливо:

- камера й мікрофон працюють лише через HTTPS (на Render він є з коробки);
- безкоштовні сервери «засинають» після ~15 хв простою. Щоб увечері сайт відповідав одразу, `.github/workflows/keepalive.yml` будить його о 16:00 за Києвом, а сервер сам себе пінгує до 01:00 і в будь-який час, поки хтось підключений (`apps/server/src/keepalive.ts`; вікно змінюється змінною `KEEP_AWAKE_HOURS`, напр. `18-2`, або `off`). Цілодобово не тримаємо, бо ліміт 750 безкоштовних годин на місяць спільний для всіх сервісів акаунта. GitHub вимикає розклад у репозиторіях без комітів понад 60 днів — тоді його треба ввімкнути знову у вкладці Actions;
- умови безкоштовних тарифів змінюються — перевірте сторінки з цінами перед вибором.
